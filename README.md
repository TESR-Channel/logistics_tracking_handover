# TESR — Tracking & Handover Record

Single-file web app for TESR Shop delivery handover records, deployed on GitHub Pages.

- `index.html` — the whole app (UI, customer database, logo)
- `tesr-drive-backend.gs` — Google Apps Script backend (Drive + Sheet log)
- `manifest.json` + `icon-*.png` / `apple-touch-icon.png` / `favicon-32.png` — app icons for Add to Home Screen (iPhone/iPad/Android) and browser tab

Upload all files to the repo root. On iPhone/iPad: open the site in Safari → Share → Add to Home Screen → the TESR parcel icon appears.
